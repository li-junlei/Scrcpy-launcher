# 文件互传

点击工具箱中的「文件互传」打开独立双栏窗口。左侧是电脑，右侧是选中的手机；多台设备连接时请先选择设备。

- 默认打开电脑用户目录、手机 `/sdcard`。通过路径栏、双击目录、上级按钮浏览；电脑「磁盘」列出磁盘，手机「根目录」打开 `/`。
- 勾选文件、文件夹或全选后，点击「上传到手机」或「下载到电脑」。另一侧当前显示的目录是目标目录。
- 文件夹递归传输并保留结构；同名顶层项目跳过，不合并或覆盖。符号链接不支持勾选，目录链接可双击浏览。
- 开始前统计总字节，传输时显示当前文件名、单文件字节进度和总字节进度，并保留已处理项目数。失败/跳过的字节不计入已传输。结束后显示逐项结果，自动刷新目录。
- 手机范围取决于 ADB 权限，无法访问的目录显示错误。下载遇到 Windows 不支持的文件名可能失败。
- 传输失败可能留下不完整文件或目录；请检查结果并移走或删除残留后重试。传输过程中无法关闭该窗口。

## 实现入口

`src/file_manager.rs` 注册目录浏览、设备选择和批量传输命令；目录通过 ADB SYNC LIST 读取，文件通过 SEND/RECV 原生传输，程序递归创建目录（含空目录）。`dist/file-manager.html`、`.css`、`.js` 构成独立前端。原主界面拖拽发送到手机下载目录的快捷功能保留。

## v2.8.2 字节进度

上传和下载均按实际数据块更新字节数，分别展示当前文件进度、整批总进度和文件名称。开始前统计选中内容的总字节；目录内文件逐个跟踪，空文件完成后显示 100%。同名跳过或失败时保留实际已传字节，不把未传数据补成 100%。进度事件至多每 100 毫秒推送一次，文件开始和结束立即推送。

验证：新增跨文件累计及空文件进度单元测试、前端双进度条数值检查，实机上传和下载的累计字节均等于统计总字节。界面操作仍由用户自行验收。

## v2.8.3 关闭与速度

文件互传窗口空闲时可以正常关闭。关闭监听使用的 Tauri 默认销毁操作已授予该窗口专属权限；传输期间仍防止误关。

单文件及总进度旁增加实时速度，采用最近约一秒的字节增量计算，每 250 毫秒刷新。单文件速率在切换文件时重置，停传时回落到零，结束后显示 0 B/s。
